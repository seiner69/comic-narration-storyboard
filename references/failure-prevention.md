# Failure prevention

| Failure or correction | Preventive rule |
|---|---|
| Opening was analytical, indirect or emotionally flat | Enter a concrete conflict, cost or expectation appropriate to this story; do not force an identity hook or rewrite an approved opening. |
| Reference copy sounded too close to the ASR script | Transfer narrative functions such as information timing, viewpoint, dialogue selection and emotional contrast, not signature wording or plot facts. Reconfirm every name, event and relation from the comic. |
| Script missed the nominal duration | Report the honest duration. Never add repeated explanation just to meet minutes. |
| Two frames showed the same subject without a reason | Record the purpose of reuse, vary a legitimate motion phase and cap the exact panel at three displays. |
| Review considered only selected crops | Build context views containing the candidate and nearby art above and below; inspect every segment. |
| Matching relied on OCR | Evaluate subject, action, result, reaction, object, location and chronology; use OCR only as secondary evidence. |
| A weak frame was accepted because it was nearby | Replace the wrong actor/action with direct art. For dialogue-grounded background or emotion, use a relevant speaker/listener/state and retain necessary facts. Do not delete facts just to satisfy isolated-image matching. |
| Dialogue, narration, SFX or phone UI occupied a useful part of the frame | Remove the contiguous text band first. If the remaining art is incomplete or cannot support the line independently, reselect the speaker, listener, action, reaction or object and rewrite the line when necessary. |
| A person or action was cropped while art continued across files | Locate the full panel in the canonical stream and perform cross-source extraction. |
| Dialogue was clipped and triggered unnecessary repair | Ignore dialogue continuity unless the text itself is the indispensable object; preserve art, not bubble geometry. |
| Several adjacent scenes were treated as one “complete panel” | Detect location, time, border, composition and action-phase changes before extraction. Split independent scenes into separate shots instead of compressing the whole strip. |
| A single selected region remained too tall to read at 4:3 | Remove text and blank bands, then crop to the shortest complete narrated scene. Use same-source blur only afterward; if the clear foreground is under 32% of canvas width, require manual approval or shorten/reselect. |
| Older visuals or coordinates leaked into a new edition | Re-read the new canonical source and re-extract every final original; use the old delivery only for style comparison. |
| A later chapter leaked into the episode | Enforce allowed chapters in provenance validation and inspect source lists for out-of-range IDs. |
| Metrics became stale after a targeted fix | Rebuild script, mappings, contact sheets and metrics after every final mapping change. Compute counts from the final inventory. |
| A validator failed because counts were hard-coded | Parameterize expected dimensions and chapters; derive unit, segment and source counts from current files. |
| Automated QC claimed text-majority count zero despite obvious text screens | Perform a manual contact-sheet pass and record repaired segments. Automated metrics cannot replace visual inspection. |
| A protected prior delivery was changed | Hash protected files before work and verify the hashes at final validation. Retire superseded files to a recoverable backup. |
| One sentence forced one image and the story became a sequence of captions | Separate paragraphs, semantic units, visual segments and panels. Compose the whole conflict; cut on changes of action, reaction or information. |
| Action→result→reaction became a mandatory sentence factory | Use the chain to check continuity, not to ration judgments, sentence lengths or descriptive passages. |
| Adding dialogue or adjectives still left narration emotionally flat | Let the narrator selectively express supported expectations, perspective, contrast and emotional cost; retain plain connective prose elsewhere. |
| “Write like a novel” introduced invented motives or attacks | Distinguish a nonliteral treatment of an established event from a new factual claim. Verify precise mental states; do not convert a genuine plea into a calculated disguise. |
| Every reference technique was applied to every scene | Select techniques for the scene's effect. Do not impose humor on grief or a suspense twist where the source establishes no secret. |
| Removing speech bubbles removed the story's necessary explanations | Keep textual fact evidence separate from displayed-art suitability; source dialogue remains authoritative when not shown. |
| An approved-panel rewrite silently re-cropped art or ran a full-render validator | Honor the mapping-only contract, preserve source hashes, and validate its actual fields rather than invent missing deliverables. |
| A character's grievance became the narrator's unqualified verdict | Attribute the belief at the ambiguous line, or retain the verified question in the character's own voice. Do not invent dialogue to solve attribution. |
| The same hesitation was described repeatedly without changing the exchange | Cut repeated-state narration and obsolete visual replays, while retaining a concrete contrast or callback whose meaning changes. |
| An emotionally uncomfortable grievance was softened into a flattering motive | Preserve the actual accusation, including material or status concerns. Focal sympathy is not authorization to rewrite a character's reasons. |
| Every feedback round discarded an accepted structure, or a requested fresh rewrite merely changed synonyms | Distinguish targeted correction from re-reading/recomposition. Preserve approved strengths in the former; let fresh source comprehension determine the latter. |
| The accepted paragraph CSV failed a helper expecting an order column | Use the explicit file-order option for that schema; do not insert guessed chronology or run a schema-incompatible validator. |

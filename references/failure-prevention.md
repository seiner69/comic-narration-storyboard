# Failure prevention

| Failure or correction | Preventive rule |
|---|---|
| Opening was analytical, indirect or emotionally flat | State the identity contrast and present cost in the first few short units; enter scene one immediately afterward. |
| Reference copy sounded too close to the ASR script | Extract cadence and sentence mechanics only. Reconfirm every name, event and relation from the comic. |
| Script missed the nominal duration | Report the honest duration. Never add repeated explanation just to meet minutes. |
| Two frames showed the same subject without a reason | Record the purpose of reuse, vary a legitimate motion phase and cap the exact panel at three displays. |
| Review considered only selected crops | Build context views containing the candidate and nearby art above and below; inspect every segment. |
| Matching relied on OCR | Evaluate subject, action, result, reaction, object, location and chronology; use OCR only as secondary evidence. |
| A weak frame was accepted because it was nearby | Reselect or expand; if no visual evidence exists, rewrite the narration. |
| Dialogue, narration, SFX or phone UI occupied a useful part of the frame | Remove the contiguous text band first. If the remaining art is incomplete or cannot support the line independently, reselect the speaker, listener, action, reaction or object and rewrite the line when necessary. |
| A person or action was cropped while art continued across files | Locate the full panel in the canonical stream and perform cross-source extraction. |
| Dialogue was clipped and triggered unnecessary repair | Ignore dialogue continuity unless the text itself is the indispensable object; preserve art, not bubble geometry. |
| Several adjacent scenes were treated as one “complete panel” | Detect location, time, border, composition and action-phase changes before extraction. Split independent scenes into separate shots instead of compressing the whole strip. |
| A single selected region remained too tall to read at 4:3 | Remove text and blank bands, then crop to the shortest complete narrated scene. Use same-source blur only afterward; if the clear foreground is under 32% of canvas width, require manual approval or shorten/reselect. |
| Older visuals or coordinates leaked into a new edition | Re-read the new canonical source and re-extract every final original; use the old delivery only for style comparison. |
| A later chapter leaked into the episode | Enforce allowed chapters in provenance validation and inspect source lists for out-of-range IDs. |
| Metrics became stale after a targeted fix | Rebuild script, mappings, contact sheets and metrics after every final mapping change. Compute counts from the final inventory. |
| A validator failed because counts were hard-coded | Parameterize expected dimensions and chapters; derive unit, segment and source counts from current files. |
| Automated QC claimed text-majority count zero despite obvious text screens | Perform a manual contact-sheet pass and record repaired segments. Automated metrics cannot replace visual inspection. |
| A protected prior delivery was changed | Hash protected files before work and verify the hashes at final validation. Retire superseded files to a recoverable backup. |
